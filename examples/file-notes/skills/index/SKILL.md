# Навык: оглавление и поиск

## Когда применять

Используй этот навык после создания, переименования или удаления заметки, а
также когда пользователь просит найти заметку.

## Формат `notes/index.md`

```markdown
# Оглавление заметок

- [<title>](<YYYY-MM-DD-слаг.md>) — <tag1>, <tag2> — <YYYY-MM-DD>
```

Список сортируется по дате заметки, новые сверху. Дубликаты не допускаются.

## Обновление оглавления

1. Прочитай `notes/index.md`. Если файла нет — создай по шаблону выше.
2. Прочитай первые строки заметки (frontmatter) через `read_file`, чтобы взять
   `title`, `date`, `tags`.
3. Замени строку с этой заметкой или добавь новую в правильном месте.
4. Запиши файл через `write_file`.

## Поиск

1. Сначала посмотри `notes/index.md`.
2. Если совпадений мало, просмотри список файлов в `notes/` через
   `list_files` и прочитай подходящие заметки.
3. В ответе укажи относительные пути и короткие цитаты (до 200 символов).

## Ограничения

- Не создавай `notes/index.md` вне `notes/`.
- Не удаляй строки других заметок, если они не помечены как устаревшие.
- Если оглавление рассинхронизировано с файлами, предложи пересобрать его
  целиком, а не править наугад.
