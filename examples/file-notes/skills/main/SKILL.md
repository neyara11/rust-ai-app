# Навык: ведение заметок

## Когда применять

Используй этот навык, когда пользователь просит создать, обновить или
переименовать заметку.

## Шаги

1. Определи тему заметки и предложи короткий слаг из латиницы, цифр и дефисов
   (например, `meeting-notes`, `release-1-2`). Если слаг неочевиден — уточни.
2. Имя файла: `notes/YYYY-MM-DD-<слаг>.md` (дата — сегодняшняя, если
   пользователь не указал другую).
3. Прочитай существующий файл через `read_file`, если он уже есть. Не
   перезаписывай чужие правки молча.
4. Структура заметки:

   ```markdown
   ---
   title: <заголовок>
   date: <YYYY-MM-DD>
   tags: [<тег1>, <тег2>]
   ---

   ## Контекст

   <зачем эта заметка>

   ## Содержание

   <основной текст>

   ## Следующие шаги

   - [ ] <действие, если есть>
   ```

5. Запиши файл через `write_file` (новый) или `append_file` (дополнение).
6. Обнови `notes/index.md` по навыку `index`.
7. Ответь списком изменённых файлов.

## Ограничения

- Только `notes/` и `notes/index.md`; не трогай другие файлы рабочей папки.
- Максимум 64 КиБ на одну заметку; длинные тексты разбивай на части.
- Никаких секретов, паролей и токенов в заметках.
