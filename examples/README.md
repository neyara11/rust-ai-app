# Примеры мини-приложений

`file-notes/` — исходники пакета «Заметки в рабочей папке»: навыки (`skills/`),
системный промпт (`prompt/`) и манифест с доступом к рабочей папке. `hashes` пустые,
поэтому это именно исходники для `validate → build → sign`.

`file-notes-workspace/` — пример рабочей папки для проверки (скопируйте её
содержимое в рабочую папку приложения).

`skill-only/` — **готовый** пример: манифест, `file_scopes: ["workspace"]`,
`hashes` и dev-подпись. Его можно сразу установить и проверить навык выжимки.

`skill-only-source/` — те же `AGENTS.md` и `SKILL.md`, но без манифеста. На нём
проверяется генерация манифеста мастером.

## Проверить готовый skill-only

1. Каталог → «Установить» → путь `examples/skill-only` (или `--install`).
2. Откройте приложение, выберите рабочую папку.
3. Положите в неё любой `.md`/`.txt`, попросите: «сделай выжимку по файлу …».
4. Ожидаемо: агент читает файл и создаёт `summary.md`.

## Быстрый тест генерации манифеста

1. Скопируйте `examples/skill-only-source` в отдельную папку, например
   `D:\apps\skill-only`.
2. Платформа → «Мастер пакета» → укажите папку → «Загрузить».
3. В логе будет: `AGENTS.md: найден`, `навыков: 0 + корневой SKILL.md`,
   `manifest.json: нет`.
4. Проверьте `app_id` (подставится из имени папки), выберите шаблон `files`
   (нужен доступ к рабочей папке) и нажмите «Создать манифест из исходников».
5. Мастер создаст `manifest.json`, перенесёт `AGENTS.md` в `prompt/system.md`,
   а `SKILL.md` — в `skills/main/SKILL.md` (перенос).
6. Далее «Проверить» → «Собрать zip» → «Подписать» → «Установить».

## Быстрый тест упаковки file-notes

1. Скопируйте `examples/file-notes` в отдельную папку, например
   `D:\apps\file-notes` — пример в репозитории не стоит собирать на месте,
   `build` меняет `manifest.json`, а `sign` создаёт `manifest.sig`.
2. Откройте платформу → вкладка **«Мастер пакета»**.
3. Укажите папку `D:\apps\file-notes`, нажмите «Загрузить».
4. «Проверить» — ожидаемо ошибка про `hashes`: исходники ещё не собраны.
5. «Собрать zip» — пересчитает `hashes` и создаст `D:\apps\file-notes-0.1.0.zip`.
6. Dev-ключ: путь из профиля подставляется автоматически; иначе «Создать ключ…»
   (`eco-pack keygen`).
7. «Подписать» → «Установить». Пакет появится в каталоге.
8. Откройте приложение, выберите рабочую папку и скопируйте туда
   `file-notes-workspace/notes`.
9. Проверьте сценарий: «создай заметку про проверку упаковки», «найди заметку
   про релиз», «обнови оглавление».

То же самое из CLI:

```powershell
eco-pack validate D:\apps\file-notes
eco-pack build D:\apps\file-notes
eco-pack sign D:\apps\file-notes --key D:\keys\me\dev.key
```

Подробные требования к исходникам — `docs/MINIAPP_AUTHORING.md`.
