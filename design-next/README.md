# ECO AIOps — design-next

Статический кликабельный прототип нового интерфейса. Текущее приложение в `../src` не используется и не изменяется.

Визуальная оболочка перенесена в `../src` (`index.html`/`styles.css`), прототип остаётся эталоном и по-прежнему не используется рантаймом.

## Как открыть

Двойной клик по `index.html` в Chrome или:

```powershell
python -m http.server 5178 --bind 127.0.0.1
```

Затем открыть <http://127.0.0.1:5178/>.

## Что это

- Только фронтенд: никаких Tauri-команд, сетевых запросов и сборки.
- Демо-данные в `data.js` и `sessions.js`, состояние — в памяти.
- В `localStorage` сохраняются тема, свёрнутость сайдбара и настройки.
- Тёмная и светлая темы, переключатель в левом нижнем углу.

## Отличия от макета в `D:\git\promtail\design-app`

- Верхний бар больше не перекрывает прокручиваемый контент.
- Ужесточён контраст вторичного текста и основной кнопки в светлой теме.
- «Подпись ок», «локальный seal» и «блок» — разные состояния.
- MCP-консоль ограничена allow-list пакета и его MCP-подключениями.
- Политика внешней записи берётся из режима контура, а не из конкретного экрана.
- Тосты перенесены из-под композера наверх, у предупреждений нормальная иконка.
- «Завершить сессию» больше не стирает диалог; удаление сессии — отдельным пунктом с подтверждением.
- Удаление дампов и сброс конфигурации требуют подтверждения.
- Каталог на 900×600 показывает две колонки вместо одной.
- Иконка настроек заменена на шестерёнку; в свёрнутом сайдбаре нижняя группа прижата к низу и выровнена по шагу.
- В свёрнутом виде история чатов доступна выпадающей панелью: иконка часов, иконка поиска или Ctrl+K.

Это по-прежнему макет, а не production-код: нативные диалоги, реальные MCP-вызовы, стриминг, диаграммы и Tauri-интеграция не реализованы.
