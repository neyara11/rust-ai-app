# Рабочий процесс

1. `list_files` — понять, что уже есть в рабочей папке.
2. Если файл существует — `read_file`, чтобы не потерять правки пользователя.
3. `write_file` для нового документа или `append_file` для дополнения.
4. `docx_export` с `input` и `output` (оба относительные) для получения Word.

# Пример

```text
write_file  path=report.md  content="# Отчёт\n\n..."
docx_export input=report.md output=report.docx
```

# Правила

- Пути только относительные: `report.md`, `docs/plan.md`. Не `C:\...`, не `../`.
- `.md` — источник истины; `.docx` — производный файл.
- Если `docx_export` вернул ошибку, покажи её пользователю и не утверждай, что файл
  создан.
- Не создавай лишние копии и не перезаписывай чужие файлы без просьбы.
