# Чтение Office

`platform_read_office input=report.docx output=report.extracted.md` создаёт:

- `report.extracted.md` — текст, заголовки, списки, таблицы и ссылки на картинки;
- `report.extracted.assets/` — извлечённые картинки и вложенные Office-файлы.

Для xlsx в markdown есть раздел `## Лист: <имя>` с размером листа, объединениями
и пометкой обрезки. Формулы сохраняются как `=SUM(...)`, значения не
пересчитываются. Если лист больше 200×40, в файле только начало и пометка —
попроси пользователя сузить диапазон или разбей данные.

Читай только `.docx` и `.xlsx`. Форматы `.doc`/`.xls`, макросы и пароли не
поддерживаются: попроси пересохранить файл.

# Word из markdown

`platform_docx_export input=report.md output=report.docx` понимает:

- заголовки `#`…`######`, абзацы, `**жирный**`, `*курсив*`, `` `код` ``;
- маркированные и нумерованные списки;
- цитаты `> `, блоки кода в ``` ```;
- таблицы GFM (первая строка — заголовок);
- картинки отдельной строкой: `![Подпись](chart-1.png)`.

Пути к картинкам — относительно markdown-файла, только внутри рабочей папки.
HTML, сноски, оглавление и поля Word не поддерживаются.

В чате PNG-ссылки не показываются: для предпросмотра используй блоки `chart` и
`mermaid` из скила `diagrams`, а ссылки на PNG оставляй только в файлах.

# Excel из markdown

`platform_xlsx_export input=report.md output=report.xlsx`: каждый заголовок второго
уровня (`##`) становится листом, первая таблица под ним — данными. Несколько
таблиц под одним заголовком получают листы с суффиксом. Числа распознаются
автоматически, первая строка становится заголовком с фильтром.

Для нескольких листов, формул, объединений, форматирования и графиков
используй `workbook.json`: `platform_xlsx_export input=workbook.json output=report.xlsx`.

# workbook.json

```json
{
  "title": "Отчёт за квартал",
  "sheets": [
    {
      "name": "Метрики",
      "columns": ["Метрика", "Январь", "Февраль"],
      "rows": [["Вызовы", 10, 14], ["Ошибки", 2, 1]],
      "widths": [24, 12, 12],
      "formats": {"B2": "0", "B3": "0.0%"},
      "merges": ["A4:C4"],
      "freeze": "A2",
      "autofilter": "A1:C3",
      "charts": [
        {
          "type": "bar",
          "title": "Динамика",
          "anchor": "E2",
          "categories": "A2:A3",
          "series": [
            {"name": "Январь", "values": "B2:B3"},
            {"name": "Февраль", "values": "C2:C3"}
          ]
        }
      ],
      "images": [
        {"path": "chart-1.png", "anchor": "E20", "width": 5}
      ]
    }
  ]
}
```

Правила:

- `name` — до 31 символа, без `[]:*?/\`;
- строки — массив массивов, формулы начинаются с `=`;
- `charts.type`: `bar`, `column`, `line`, `area`, `pie`, `doughnut`, `radar`,
  `scatter`; для scatter у series задаются `x` и `y`;
- диапазоны — `A2:A10`, `B2:B10`; `anchor` — ячейка листа;
- `images.path` — PNG внутри рабочей папки, ширина/высота в дюймах.

# Проверка перед ответом

1. Исходники (`*.md`, `*.json`, `*.mmd`) и PNG лежат рядом с результатом.
2. В ответе инструмента `ok: true` и ненулевой `bytes`.
3. В markdown нет абсолютных путей и ссылок на отсутствующие PNG.
4. Для xlsx с графиком указан диапазон, где реально есть числа.
