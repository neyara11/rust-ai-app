# Справка по библиотеке через context7

## Когда применять

- Нужен точный синтаксис или поведение API конкретной библиотеки.
- Есть подозрение, что знание устарело: версия изменилась, API переехал.
- Нужен рабочий пример кода, а не пересказ.

Не применять для общих вопросов («что такое HTTP»), для кода проекта и для задач, где
источником истины является сам репозиторий.

## Маршрут

1. **Сформулируй один узкий вопрос.** Не «всё про Tauri», а «как называются аргументы
   команды при вызове из JS и что делает rename_all».
2. **`resolve_library_id`**: официальное имя библиотеки (`Tauri`, `Next.js`, `Prisma`) и
   тот же узкий вопрос как `query`.
3. **Выбери ID.** Приоритет: точное совпадение имени, затем совпадение версии с проектом,
   затем выше source reputation и больше сниппетов. `libraryId` вида `/org/project` или
   `/org/project/version`.
4. **`query_docs`**: `libraryId`, `language` (язык проекта) и **один** вопрос. Если вопрос
   распадается на два независимых — это два вызова, а не один длинный.
5. **Сверь версию.** Версия из ответа должна совпадать с версией в проекте. Если нет —
   проговори расхождение или запроси конкретную версию в `libraryId`.
6. **Ответ**: короткий вывод, фрагмент кода, `libraryId` и версия. Без пересказа всей статьи.

## Ограничения

- Не больше трёх обращений на один вопрос. Если не нашлось — переформулируй один раз, затем
  честно верни «в документации не найдено».
- Не дублируй запрос с теми же словами: меняй формулировку, а не терпение.
- Не проси «примеры» и «всю документацию» — проси поведение.

## Примеры

Плохо: `resolve("Tauri", "документация")` → `query("...", "расскажи про Tauri")`.

Хорошо:

1. `resolve("Tauri", "command argument naming camelCase snake_case rename_all")`
2. `query("/tauri-apps/tauri", "...", "How are #[tauri::command] arguments named when invoked from JS?")`
3. Ответ: «по умолчанию camelCase; `rename_all = "snake_case"` оставляет snake_case» +
   ссылка на `crates/tauri-macros/src/command/wrapper.rs`.

## Выход

Если пользователь просит зафиксировать результат, добавь короткую выжимку в документ
`findings`: вопрос, ответ, `libraryId`, версия, дата. Не копируй туда весь ответ.
