# UI smoke test

Опциональный dev-прогон интерфейса без Tauri: статический сервер на `src/`
и встроенный mock (`browserMock` в `app.js`), поэтому поднимать движок и
профиль не нужно.

```powershell
cd tools\ui-smoke
npm install     # нужен только playwright
npm test
```

Проверяется: каталог из трёх пакетов, бейдж allowlist, запрет открытия
недоверенного пакета, рендер чата с markdown/статистикой и переключение
приложения. Это dev-инструмент; рантайму платформы npm не требуется.
