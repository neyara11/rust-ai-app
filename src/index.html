Настройки приложения

                
Переопределения действуют только для этого пакета. Глобальные настройки остаются значениями по умолчанию.

              

              
            


            

              

                

                  

                    
                  

                  

                    
MCP для приложения

                    
Один и тот же id может иметь разные URL, токены и TLS-политику в разных приложениях. Без override используется глобальный реестр.

                  

                

                

              


              

                

                  

                    
                  

                  

                    
Переменные инструментов

                    
Секреты, объявленные в tools[].secrets. Значения хранятся в DPAPI с namespace приложения и не попадают в пакет.

                  

                

                

              


              

                

                  

                    
                  

                  

                    
Подтверждения

                    
Переопределение политики для пакета. «Всегда» доступно для записи и exec-инструментов из пакета, покрытых хешем; workspace-exec остаётся под запросом.
